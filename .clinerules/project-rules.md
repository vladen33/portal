# Правила работы ИИ-агента в проекте «portal»

## Стек и окружение
- Язык: Python 3 + фреймворк Django.
- БД для быстрой разработки: SQLite 3 (локально).
- БД для проверки функций, зависящих от СУБД: MS SQL Server в
  Docker-контейнере (deploy/docker-compose.mssql.yml).
- БД в production: MS SQL Server.
- Виртуальное окружение называется "venv", не ".venv".

## Стиль кода Python
- Длина строки — не более 80 символов.

## Комментарии
- Python и особенно Django: комментируем подробно.
  Комментарии на русском языке, адресованы разработчику, который
  владеет Python и на уровне junior знает Django.
- JavaScript: только короткие и очень краткие комментарии.
- HTML: комментарии не делаем.
- CSS: комментарии допустимы, но очень краткие — одна строка, пара слов
  о том, к какому блоку относится правило.

## Общее
- Придерживаться существующих соглашений и структуры проекта.

## Тестирование
- Для запуска тестов используем `pytest -n auto`, чтобы тесты
  выполнялись параллельно на всех доступных ядрах процессора.
- Не запускать тесты просто командой `pytest`; последовательный
  запуск допустим только для отладки конкретного теста, если это
  явно оговорено.
- Без активации `venv` используем
  `venv/bin/python -m pytest -n auto`.
